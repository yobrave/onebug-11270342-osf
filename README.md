# One Star, Five Stars for the Food

An alien tourist's one-star review of Earth that still compliments the food, in one line under 200 characters. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
